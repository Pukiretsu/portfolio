# Análisis de la calidad del aire en Bogotá

Para un proyecto universitario, ayudé a construir un pipeline ETL y una aplicación web para explorar la calidad del aire en Bogotá.

## Recopilación y procesamiento de datos

Un rastreador web en Docker recopiló los datos de calidad del aire. El pipeline ETL utilizó Python y pandas para procesar los registros.

## Mapas e informes

Un sitio en Vue mostró los resultados con datos de sistemas de información geográfica (SIG). Los microservicios en Python generaron informes y calcularon índices de calidad del aire para períodos seleccionados.
