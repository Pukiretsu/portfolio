# Bogotá air quality analytics

For a college project, I helped build an ETL pipeline and web application for exploring air quality across Bogotá.

## Data collection and processing

A Dockerized web crawler collected air quality data. The ETL pipeline used Python and pandas to process the records.

## Maps and reporting

A Vue site displayed the results using GIS data. Python microservices generated reports and calculated air quality indices for selected time spans.
