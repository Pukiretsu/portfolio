# Análise da qualidade do ar em Bogotá

Em um projeto universitário, ajudei a construir um pipeline de ETL e um aplicativo web para explorar a qualidade do ar em Bogotá.

## Coleta e processamento de dados

Um rastreador web no Docker coletou dados de qualidade do ar. O pipeline de ETL usou Python e pandas para processar os registros.

## Mapas e relatórios

Um site em Vue exibiu os resultados com dados de sistemas de informação geográfica (SIG). Microsserviços em Python geraram relatórios e calcularam índices de qualidade do ar para os períodos selecionados.
