# Portfolio frontend

Vue and Vite, with a single welcome page. Use Node.js 24 LTS.

```sh
npm ci
npm run dev
```

Edit `src/App.vue` for content and `src/style.css` for styling.

```sh
npm run build
npm run preview
```

The production site is generated in `dist/`. Never place secrets in frontend code or `VITE_*` variables: they are visible to visitors.
